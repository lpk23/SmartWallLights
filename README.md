# SmartWallLights

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3782121141)

## Русский

SmartWallLights - мод для RimWorld 1.6, который помогает быстро расставлять настенные светильники в комнате.

Выберите настенный светильник, зажмите Shift и наведите курсор на стену комнаты. Мод покажет предпросмотр будущей расстановки и после клика разместит светильники автоматически.

### Особенности

- Быстрая расстановка настенных светильников по комнате.
- Предпросмотр позиций перед установкой.
- Несколько режимов расстановки: эффективный, симметричный и гибридный.
- Учет дверей, чтобы светильники не появлялись прямо у проходов.

### Требования

- RimWorld 1.6
- Harmony

## English

SmartWallLights is a RimWorld 1.6 mod that helps place wall lights around a room quickly.

Select a wall light, hold Shift, and hover over a room wall. The mod previews the planned layout and places the lights automatically after you click.

### Features

- Fast wall light placement by room.
- Preview before placement.
- Multiple placement modes: efficient, symmetric, and hybrid.
- Door-aware placement so lights are not placed directly next to doorways.

### Requirements

- RimWorld 1.6
- Harmony
